# Tindahan+ Website

Production static website for the Tindahan+ Android point-of-sale application.

## Pages

- `/` — product landing page
- `/privacy/` — privacy policy

## Deployment

No build step is required. Deploy the repository root with GitHub Pages or any static hosting provider. Relative links are used so the site also works under a project path.

## Production checklist

- Keep the privacy policy synchronized with the Android app's actual behavior.
- Add the public Google Play/support URL when available.
- Configure a custom domain and HTTPS if desired.
- Test the deployed site on mobile and desktop after publishing.
